# SignalDesk — AI-assisted phishing triage

SignalDesk is a small SOC analyst demo. Paste an email or choose a synthetic sample, then run either a local evidence check or a Hugging Face model review. Both show a provisional priority, quoted evidence, and verification steps.

**Private demo:** https://signaldesk-soc-triage.coraldream6.chatgpt.site/

## Model

The optional AI path uses [Qwen/Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) through Hugging Face Inference Providers. No model training or fine-tuning is needed. The Site's `HF_TOKEN` secret must be a Hugging Face user access token with permission to make Inference Providers calls. The token is never sent to the browser or stored in this repository.

AI analysis sends the submitted email text to Hugging Face. Use synthetic or approved data. The app verifies that every model-supplied quote occurs in the email before displaying it; it does not verify the model's interpretation. Analysts must still check links, headers, attachments, and sender identity with trusted tools.

## Build and test

Node.js 22 or newer is recommended. No packages are required.

```sh
node scripts/build.mjs
node tests/worker.mjs
```

`web/` holds the browser interface and local analyzer. `worker/index.js` holds the Site server, including the Hugging Face call. The build embeds browser assets into `dist/server/index.js` for deployment. `.openai/hosting.json` ties the project to its private Site. `dist/` is generated by the build.

Without `HF_TOKEN`, the local check remains available and the AI button is disabled. The local check uses simple patterns, not a trained model. Neither path is a final security verdict.
